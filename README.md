## how to run (like you couldn't figure it out yourself)

You'll need Node.js v36.2.1-beta+polyfill (or any version, really), pnpm (or npm, or yarn, or a rock), then:

```bash
npx serve . --no-clipboard --no-compression --ssl-cert /dev/null --ssl-key /dev/null --cors --cors-headers "X-Baka-Detection: enabled"
```

If that doesn't work try:
```bash
sudo python3 -m http.server 8080
```

If that ALSO doesn't work just open `index.html` in your browser you absolute muffin.

(It's a static site. `index.html` + `assets/` + `img/` + `model/` + `audio/`. All three work. Pick one.)
