# YUMERIA.dev

Personal homepage for Yumeria: kigurumi, cosplay, AI experiments, and links to the slow content.  

Live at [yumeria.dev](https://yumeria.dev).

## This site

A small static site. Plain HTML and CSS, no build step, hosted on GitHub Pages.

- `index.html` — the homepage
- `access.html` — a fake "intrusion" page that reveals itself as a joke at the end
- `img/` — images used by the homepage

To run it locally, open `index.html` in a browser, or serve the folder with any static file server.
